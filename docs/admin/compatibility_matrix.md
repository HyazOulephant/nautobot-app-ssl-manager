# Compatibility Matrix

The app follows [Semantic Versioning](https://semver.org/spec/v2.0.0.html): breaking changes are only introduced in major versions.

| Nautobot SSL Manager Version | Nautobot First Support Version | Nautobot Last Support Version |
| ---------------------------- | ------------------------------ | ----------------------------- |
| 1.2.X                        | 3.1.0                          | 3.99.99                       |
| 1.1.X                        | 3.1.0                          | 3.99.99                       |
| 1.0.X                        | 3.1.0                          | 3.99.99                       |

Supported Python versions: 3.10 to 3.14.

Optional integration (since 1.2.0): [Nautobot DNS Models](https://github.com/nautobot/nautobot-app-dns-models) 2.3.0 or higher.
