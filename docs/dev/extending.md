# Extending the App

Extending the application is welcome, however it is best to open an [issue](https://github.com/HyazOulephant/nautobot-app-ssl-manager/issues) first, to ensure that a PR would be accepted and makes sense in terms of features and design.

Without changing the code, the app models can be extended with the standard Nautobot features: custom fields, relationships, custom links, custom validators, export templates, webhooks and statuses.
